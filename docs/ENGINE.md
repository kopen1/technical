# Diagnostic Engine

Pipeline V0.1:
Symptom -> Initial Tests -> Rule Matching -> Published Evidence -> Next Step.

Prinsip:
- Symptom bukan fault.
- 0A bukan otomatis satu kerusakan.
- Buzzer/continuity bukan otomatis short.
- 0V bukan otomatis ground.
- Model/board/revision harus diperhatikan.
- Repair case adalah evidence, bukan universal rule.

Target V0.2:
stateful diagnostic session, measurement input, evidence scoring,
branch selection, test point, expected value, verification, dan audit trail.
